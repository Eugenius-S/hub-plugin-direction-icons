# Иконки направлений — плагин Agents Hub

Свой знак у каждого направления. Внутри открытого направления, слева перед названием, — кнопка со знаком: нажмите, выберите
из набора эмодзи или введите свой («Свой знак…»); «Вернуть компас» возвращает знак по умолчанию. Выбранный знак стоит и в списке
сессий слева — вместо компаса.

- Только у направлений: у специалистов, исполнителей и хаба кнопки нет.
- Знаки хранятся в этом браузере (localStorage), на другом устройстве они свои.
- Закрывается кликом мимо или Esc. Сети и процесса у плагина нет.

## Поставить

«Настройки» → «Плагины» → вставить ссылку на этот репозиторий → «Проверить и поставить». Нужен хаб с API плагинов 1.10 (`hub.redraw`).

## Как устроено

Места `session.header` (кнопка и выбор) и `sidebar.session` (невидимая метка у строки направления). Хаб собирает строку списка и
шапку заново на каждом снимке, поэтому знак встаёт на место после сборки, до отрисовки: в строке — вместо знака у имени, в шапке
кнопка стоит перед названием. Набор знаков — `emoji.json`.

## Тесты

`python3 -m unittest discover -s tests` — стандартная библиотека, без хаба и браузера.
