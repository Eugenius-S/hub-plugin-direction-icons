# Иконки — плагин Agents Hub

Свой знак у специалистов и направлений и единый стиль всех знаков списка сессий. В шапке открытого специалиста или
направления, слева перед названием, — кнопка со знаком: нажмите и выберите из набора (эмодзи — и «Свой знак…»);
«Как было» возвращает знак хаба.
